# 长征知识竞赛

现场运行、热点连接、主持和开新比赛的步骤见 [操作说明](操作说明.md)。

主持人输入主持口令后，在赛前设置页填写读题时间、总题数和各板块题数。点击「开始比赛」会随机抽题并进入正式主持页，再从「投屏与队伍入口」打开大屏，将四队链接分别发给参赛队。

倒计时归零时开放抢答。三种题型都在抢答成功后才在主持台显示录入区。单选和判断题由主持人选择队伍答案，填空题由队伍到主持电脑逐空输入。点击「提交并判分」后可公布正确答案。倒计时结束后如果无人抢答，可直接公布答案并进入下一题。

本项目保存一场比赛的状态。新版题库来自《题库 (1).docx》，共 220 道，单选 80 道、判断 80 道、填空 60 道。每条数据中的 source 是该题在对应题型中的原始题号。

## 本地运行

需要 Node.js 24。运行 npm run dev 后访问终端显示的网址。终端会显示本次启动的主持口令，也可通过 QUIZ_SECRET 设置固定口令。比赛状态保存在本地 contest.sqlite。npm test 执行比赛流程测试，npm run build 生成 Sites Worker 部署文件。

### 手机在同一 Wi-Fi 抢答

1. 在项目目录运行 `npm run dev -- --lan`，比赛期间保持终端开启。
2. 让主持电脑和手机连到同一个 Wi-Fi。在主持电脑的浏览器打开终端中 Wi-Fi 网卡对应的主持台地址，用终端显示的口令登录。
3. 从「投屏与队伍入口」复制四队专属链接。若浏览器弹出链接文本框，手动复制其中的完整网址。将链接分别发给队伍，用手机浏览器打开。

如果手机连不上，确认队伍链接使用 Wi-Fi 网卡的 IP，并在 Windows 防火墙中允许 Node.js 在专用网络上通信。访客 Wi-Fi 可能隔离设备，可以改用允许设备互访的 Wi-Fi。
