# 长征知识竞赛

主持人在主网址输入主持口令，从「投屏与队伍入口」打开大屏，并将四个队伍链接分别发给参赛队。建议在开赛前确认四台手机均显示「已连接」。倒计时时长可在首次开始前修改。

倒计时归零时开放抢答。抢到的队伍口头作答，主持人录入并提交。判分后可公布正确答案。倒计时结束后如果无人抢答，可直接公布答案并进入下一题。

本项目保存一场比赛的状态。题库来自《题库.docx》，每条数据中的 source 是该题在对应题型中的原始题号。

## 本地运行

需要 Node.js 24。运行 npm run dev 后访问终端显示的网址。终端会显示本次启动的主持口令，也可通过 QUIZ_SECRET 设置固定口令。比赛状态保存在本地 contest.sqlite。npm test 执行比赛流程测试，npm run build 生成 Sites Worker 部署文件。
